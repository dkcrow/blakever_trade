<summary>大文件可以用sed 流式处理 (stream editor) 本质就是逐行加入内存 然后操作, 然后出内存加载下面的, 而不是一下子一整块写入再操作 适合大文件</summary>
	`sed`（Stream Editor）是Linux下非交互式的流式文本编辑器，核心原理是**逐行读取输入流（文件或管道），将当前行加载到内存的模式空间（Pattern Space），执行指令处理，然后输出结果，最后清空模式空间，处理下一行**。这种机制使其适合处理大文件。 **腾讯云 +4工作流程详情：**<br>• **读取（Read）：** `sed` 从输入流中读取一行文本。<br>• **执行（Execute）：** 将读取的行存入“模式空间”临时缓冲区，sed命令对该缓冲区中的内容进行文本替换、删除、新增等操作。<br>• **输出（Write）：** 将处理后的内容输出到屏幕或文件，默认情况下不再显示原行。<br>• **循环（Loop）：** 重复以上步骤，直到处理完整个输入流。 **腾讯云 +3**如需了解更多相关信息，可以阅读GitHub上关于sed命令工作原理的文档。**关键概念：**<br>• **模式空间（Pattern Space）：** 存放当前处理行内容的内存区域。<br>• **非交互式：** 命令直接在命令行执行，不打开文件界面。<br>• **流处理：** 文本内容像是流一样经过 sed 进行处理。

class Solution {
public:
bool isValidSudoku(vector<vector<char>>& board) {
int rows[9][9];
int columns[9][9];
int subboxes[3][3][9];
 memset(rows,0,sizeof(rows));
    memset(columns,0,sizeof(columns));
    memset(subboxes,0,sizeof(subboxes));
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            char c = board[i][j];
            if (c != '.') {
                int index = c - '0' - 1;
                rows[i][index]++;
                columns[j][index]++;
                subboxes[i / 3][j / 3][index]++;
                if (rows[i][index] > 1 || columns[j][index] > 1 || subboxes[i / 3][j / 3][index] > 1) {
                    return false;
                }
            }
        }
    }
    return true;
}
